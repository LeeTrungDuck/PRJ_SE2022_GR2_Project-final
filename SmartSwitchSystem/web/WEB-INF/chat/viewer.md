## Viewer access | DEVICE_CONTROL
Keywords: viewer role permission access quyen phan quyen xem dieu khien.
Viewer sees active switches covered by active device permissions. One is_active flag controls both viewing and controlling access. When access is revoked, the switch disappears from the permitted lists and the assistant clears chat context tied to the earlier scope. Ask an Admin or Operator to change access. Viewer cannot open User Management or Device Permissions. Viewer can edit their own account, manage schedules for permitted switches, and rename a permitted switch in Devices & Switches. Viewer cannot add or deactivate ESP32 devices or switches. Chat database reads follow current active switch access, including related schedules and anonymized history; personal account/contact data and network addresses are unavailable to the assistant for every role.
